# غرفة تحكم العملاء (Client Ops Dashboard)

لوحة تحكم داخلية لمتابعة رحلة كل عميل: حالته (نشط / معلّق / مسترد / متوقف)،
ودورة الـ 10 أيام التحضيرية بتاعته (البريف، الاستراتيجية، المحتوى، التصميمات،
الفيديوهات)، مع تنبيه أحمر تلقائي لو الميعاد فات وفيه حاجة لسه مش خالصة.

البيانات بتتحفظ في متصفحك (localStorage) — يعني تقفل وترجع تفتح تاني وتلاقي
كل حاجة زي ما سبتها. مفيش سيرفر أو داتابيز خارجية دلوقتي، ده نسخة شغالة محليًا
تقدر تبني عليها بعدين.

## تشغيل المشروع على VS Code

1. **نزّل Node.js** (لو مش مثبت عندك) من https://nodejs.org — اختار النسخة LTS.
   تأكد إنه اتثبت صح بكتابة الأمر ده في أي terminal:
   ```
   node -v
   ```

2. **فك الملف المضغوط** اللي هبعتهولك، وافتح الفولدر بتاعه في VS Code
   (File → Open Folder).

3. **افتح Terminal جوه VS Code** (من القائمة العلوية: Terminal → New Terminal)
   وسيب نفسه يكون فاتح في فولدر المشروع.

4. **ثبّت المكتبات المطلوبة** (خطوة تعملها مرة واحدة بس):
   ```
   npm install
   ```

5. **شغّل السيرفر المحلي**:
   ```
   npm run dev
   ```

6. هيطلعلك في الـ Terminal رابط شبه ده:
   ```
   Local:   http://localhost:5173/
   ```
   اضغط عليه بـ Ctrl (أو انسخه وحطه في المتصفح) وهتفتح الصفحة.

7. أي تعديل تعمله في الكود، الصفحة بتتحدث لوحدها فورًا (Hot Reload) —
   مش محتاج تقفل وتفتح تاني.

### لو عايز تبني نسخة نهائية (production) ترفعها على استضافة
```
npm run build
```
هيطلعلك فولدر اسمه `dist` فيه كل الملفات الجاهزة للرفع على أي استضافة
(Netlify, Vercel, أي هوستينج عادي...).

## هيكل المشروع
```
src/
  App.jsx                 المكوّن الرئيسي وربط كل حاجة ببعض
  styles.css               التصميم كامل
  components/
    StatusTabs.jsx          تبويبات الفلترة (نشط/معلّق/مسترد/متوقف)
    ClientCard.jsx           كارت العميل في الشبكة
    ClientDetail.jsx         صفحة تفاصيل عميل واحد + السجل
    Timeline.jsx              التايم لاين البصري لدورة الـ10 أيام
    AddClientModal.jsx        فورم إضافة عميل جديد
  utils/
    dates.js                  كل حسابات التواريخ والدورات (قابلة للتعديل)
    storage.js                 الحفظ في localStorage + بيانات تجريبية
```

## قاعدة حساب الدورة (قابلة للتعديل من `src/utils/dates.js`)
- **أول تعاقد**: العشر أيام التحضيرية تبدأ من يوم توقيع العقد نفسه، وتاريخ
  التسليم الرسمي = تاريخ التعاقد + 10 أيام.
- **كل تجديد بعد كدا**: الدورة الجديدة بتبدأ تحضيرها تلقائيًا بعد 20 يوم من
  بداية الدورة اللي قبلها (يعني آخر 10 أيام في الشهر الشغال)، عشان لما الشهر
  يخلص يكون الشغل الجديد جاهز من غير أي عطلة.

لو الحسابات دي مش مطابقة 100% لطريقة شغلك، الملف `src/utils/dates.js` فيه
شرح بالعربي جنب كل دالة عشان تعدّل عليه بسهولة.
